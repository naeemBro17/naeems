PART 1 — LINK PREVIEWS (Facebook, Messenger, WhatsApp)

How product previews worked before: link-preview robots (Facebook,
WhatsApp, …) do not run the shop's code; they only read the HTML the server
sends. vercel.json already sent ONLY robot visitors of /product/... to a
small server function, api/product-og.ts, which looked the product up and
returned a tiny HTML page with the preview tags (photo, "{name} — Naeem's",
and a description made of brand + PRICE + the start of the description).
Real shoppers never touch that function.

What changed:
- The tag-building is now in ONE shared file (api/_og.ts) used by the
  product preview and the new combo preview, so they can never drift apart.
- Product links: same full square product photo, nothing drawn on it.
  Title is now "{product name} — NAEEM'S". Description is now
  "100% authentic. Imported for you." The PRICE IS GONE. The photo is
  declared as 1200 × 1200 so Messenger shows it big. Site name "NAEEM'S".
- Shop link (home, and any page without its own preview): a new designed
  banner public/og-shop.jpg (1200 × 630, 79 KB) — frame 1 of your mockup,
  with your new wording: "100% authentic skincare, imported for you."
  ("imported for you." in the glass style), the sub-line "From Australia,
  USA, Canada, Korea, Japan, India & UK — straight to your door.", the two
  chips "Cash on delivery" · "All over Bangladesh", and a fan of 3 real
  product photos (CeraVe Foaming Cleanser, Avène Thermal Spring Water,
  Celimax Retinal Shot) on white cards — NO names and NO prices, each photo
  whole. Title "NAEEM'S — 100% Authentic Skincare", description "Imported
  from Australia, USA, Canada, Korea, Japan, India & UK. Cash on delivery
  all over Bangladesh." (The three photos were downloaded once by hand to
  make the picture; nothing downloads them at run time.)
  The picture: reports/batch-52-screens/shop-preview-og-shop.jpg
- Combo links (/c/{code}): a wide picture (1200 × 630) with the combo's
  photos (up to 4), each shown whole on a soft light background, and a
  small dark glass badge "PICKED FOR YOU". Title "{combo name} — picked for
  you by NAEEM'S", description "{n} products, hand-picked by Naeem. 100%
  authentic."
- Brand links keep their own preview; only their fallback picture is now
  the new banner.
- All tags checked: og:title, og:description, og:image + width/height,
  og:url, og:type, twitter:card = summary_large_image. The real tags the
  functions return are in reports/batch-52-screens/preview-tags.txt (also
  copied in section 4 below).

PART 3 — "SHARE AS A COMBO"

- Cart (admin only): under the cart, above the Checkout bar, a dark card
  "ONLY YOU SEE THIS" (lock icon) / "Picked these for a customer?" / "Turn
  this cart into a link. Your customer opens it and adds everything in one
  tap." and a light-outline "Share as a combo" button. It shows only when
  the real signed-in role is admin (the same isAdmin check the rest of the
  shop uses) — it is not in the page at all for anyone else. Checkout stays
  the one orange button.
- "Share as a combo" sheet: "{n} products · total ৳{total}", the product
  thumbnails, Combo name (required, up to 60 letters), Note for the customer
  (optional, up to 300 letters), orange "Create link". It saves the name,
  note, and each cart line (product, option, quantity), who made it, when,
  and a short code. No prices are saved.
- "Your combo link is ready": black circle with a tick, the name and total,
  the link with Copy (turns into "Copied"), four share buttons — WhatsApp,
  Messenger (on a phone: Messenger's share screen; on a computer: copies
  the link and says "Link copied — paste it in Messenger"), Copy, More (the
  phone's own share sheet; on a computer without one it copies) — "Your
  customer will see this in the chat:" with the preview, and "Clear my
  cart".
- Customer page /c/{code}: the product photos at the top (whole, never cut),
  soft glass background like the wishlist, "★ PICKED FOR YOU BY NAEEM", the
  combo name, "Naeem's note" card (only when there is a note), the products
  with today's price and today's stock in Batch 51 words (In Stock / Only
  {n} left — order soon / Sold out) — tapping one opens the product — then
  "Total" in near-black bold, the retail total struck through, and an
  outlined "You save ৳{x}" (only when there is a saving). Sold-out items are
  not counted. Orange "Add all to cart" adds every available item with its
  quantity, following the Batch 51 order limit and stock (and counting what
  is already in the cart), then opens the cart. When something was sold
  out: "Added {n} items. {m} sold out." Under it "Want to change something?
  Chat with us" → WhatsApp with "Hi! About my combo: {combo name}". Works
  for logged-out visitors; not listed anywhere in the shop. A deleted or
  unknown code shows "This combo isn't available anymore." with "Browse the
  shop".
- Admin → Combos (new menu item under Shopping list): each combo with its
  thumbnails, number of products, today's total, the date, and Open / Copy
  link / Share / Delete ("Delete this combo? Its link will stop working.").
  Links never expire unless deleted. Deleting also removes its preview
  picture.
- Database: two new tables (combos, combo_items) with row security — only
  the admin can make, list, change or delete; anyone with the link reads
  ONE combo through a function that returns only what the customer page
  needs. Combos never touch stock, orders, money or promo codes. Coupons
  work as normal in the cart, because a combo just fills the normal cart.

PART 4 — LEAVING FACEBOOK'S IN-APP BROWSER

- The shop recognises Facebook, Messenger and Instagram's own browsers.
- Android: on arrival — before anything is drawn, so nothing can be lost —
  the page reopens the SAME address in Chrome (if Chrome is not installed,
  the phone just stays on the normal address). This happens once per visit
  only, so it can never loop. If it does not work, the small bar below
  shows (saying "Chrome" instead of "Safari").
- iPhone (Apple does not allow the jump): a small, calm bar at the top:
  "For Google login and faster checkout, open this page in Safari." with
  "How?". "How?" opens a small sheet: "Tap ••• in the corner of the
  screen, then choose Open in browser." and a "Copy link" button. ✕ hides
  the bar for the rest of the visit.
- Tapping a Google login button inside these browsers no longer goes to
  Google's error page: the same help appears (Android tries Chrome again).
- Normal browsers see nothing different.

WHAT HAPPENS WHEN A LINK IS OPENED FROM FACEBOOK
- Android: the page opens in Facebook's browser for a moment, then Chrome
  opens on the same page by itself. The customer continues in Chrome
  (Google login works there). If Chrome does not open, they see the small
  bar and can tap "How?".
- iPhone: the page stays in Facebook's browser with the small bar at the
  top. Shopping works; only Google login needs Safari. "How?" explains
  where to tap; "Copy link" lets them paste it into Safari.

STEP BY STEP — MAKE, SHARE AND DELETE A COMBO
1. Run the SQL in section 2 once.
2. On the shop (signed in as admin), add the products to your cart with
   the right quantities and options.
3. Open the cart. Under the products you see the dark card "ONLY YOU SEE
   THIS". Tap "Share as a combo".
4. Type a name (e.g. "Sadia's glow routine") and, if you like, a note.
   Tap "Create link".
5. "Your combo link is ready": tap WhatsApp or Messenger to send it, or
   Copy and paste it anywhere. The picture under it is what your customer
   sees in the chat.
6. Tap "Clear my cart" to start the next combo (or close the sheet to keep
   your cart).
7. Later: Admin → Combos (in the menu, under Shopping list; on the phone
   it is on the More page). Open = see it as the customer does; Copy link;
   Share = the same share buttons; Delete = the link stops working.

STEP BY STEP — REFRESH OLD PREVIEWS ON FACEBOOK (Sharing Debugger)
Facebook keeps old previews for a while. After this batch is live:
1. On a computer, open https://developers.facebook.com/tools/debug/ and
   log in with your Facebook account.
2. Paste the link (e.g. https://naeems-all.vercel.app/ or a product link)
   in the box and press "Debug".
3. Press "Scrape Again". The preview at the bottom should now show the new
   picture and words.
4. Do this for the home link and for any product link you share often.
   (WhatsApp has no such tool: its preview refreshes by itself after some
   days; a link with something added, like ?v=2 at the end, shows the new
   preview at once.)

-- =====================================================================
-- Batch 52 — "Share as a combo"
--
-- Paste the whole file into the Supabase SQL Editor and press Run.
-- It is safe to run more than once.
--
-- A  combos: one shareable list of products Naeem picked for a customer
--    (name, optional note, the link code, the preview picture).
-- B  combo_items: the products in it (product, option, quantity).
-- C  Only the admin (is_admin()) can create, list, change or delete them.
-- D  get_combo(code): anyone with the link (also logged-out visitors) reads
--    ONE combo by its code — only what the customer page needs. Nobody
--    else can list combos.
--
-- Combos never touch stock, orders, money or promo codes. There is no
-- combo price: the shop's normal prices apply.
-- =====================================================================

BEGIN;

-- ---------------------------------------------------------------- A, B
CREATE TABLE IF NOT EXISTS public.combos (
  id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  -- The link: /c/{code}. 8 letters / digits, never easy to guess.
  code text NOT NULL UNIQUE CHECK (code ~ '^[a-z2-9]{8}$'),
  name text NOT NULL CHECK (char_length(btrim(name)) BETWEEN 1 AND 60),
  note text CHECK (note IS NULL OR char_length(note) <= 300),
  -- The wide picture link previews show (drawn once when it is made).
  preview_url text,
  created_by uuid REFERENCES auth.users (id) ON DELETE SET NULL DEFAULT auth.uid(),
  created_at timestamptz NOT NULL DEFAULT now()
);

CREATE TABLE IF NOT EXISTS public.combo_items (
  id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  combo_id uuid NOT NULL REFERENCES public.combos (id) ON DELETE CASCADE,
  product_id uuid NOT NULL REFERENCES public.products (id) ON DELETE CASCADE,
  -- The chosen option; null = the product itself (or its own base option).
  variant_id uuid,
  quantity integer NOT NULL CHECK (quantity BETWEEN 1 AND 99),
  sort_order integer NOT NULL DEFAULT 0
);

CREATE INDEX IF NOT EXISTS combo_items_combo_idx ON public.combo_items (combo_id, sort_order);
CREATE INDEX IF NOT EXISTS combos_created_idx ON public.combos (created_at DESC);

-- ------------------------------------------------------------------- C
ALTER TABLE public.combos ENABLE ROW LEVEL SECURITY;
ALTER TABLE public.combo_items ENABLE ROW LEVEL SECURITY;

DROP POLICY IF EXISTS combos_admin_all ON public.combos;
CREATE POLICY combos_admin_all ON public.combos
  FOR ALL TO authenticated
  USING (public.is_admin())
  WITH CHECK (public.is_admin());

DROP POLICY IF EXISTS combo_items_admin_all ON public.combo_items;
CREATE POLICY combo_items_admin_all ON public.combo_items
  FOR ALL TO authenticated
  USING (public.is_admin())
  WITH CHECK (public.is_admin());

REVOKE ALL ON public.combos FROM anon;
REVOKE ALL ON public.combo_items FROM anon;
GRANT SELECT, INSERT, UPDATE, DELETE ON public.combos TO authenticated;
GRANT SELECT, INSERT, UPDATE, DELETE ON public.combo_items TO authenticated;

-- Makes a combo and its lines in one step. Returns the new combo's id.
CREATE OR REPLACE FUNCTION public.admin_create_combo(
  p_code text,
  p_name text,
  p_note text,
  p_items jsonb
)
RETURNS uuid
LANGUAGE plpgsql
SECURITY INVOKER
SET search_path = public
AS $$
DECLARE
  v_id uuid;
  v_item jsonb;
  v_index integer := 0;
BEGIN
  IF NOT public.is_admin() THEN
    RAISE EXCEPTION 'Only the admin can make a combo.' USING ERRCODE = '42501';
  END IF;
  IF p_items IS NULL OR jsonb_typeof(p_items) <> 'array' OR jsonb_array_length(p_items) = 0 THEN
    RAISE EXCEPTION 'A combo needs at least one product.';
  END IF;
  IF jsonb_array_length(p_items) > 50 THEN
    RAISE EXCEPTION 'A combo can have up to 50 products.';
  END IF;

  INSERT INTO public.combos (code, name, note)
  VALUES (p_code, btrim(p_name), NULLIF(btrim(coalesce(p_note, '')), ''))
  RETURNING id INTO v_id;

  FOR v_item IN SELECT value FROM jsonb_array_elements(p_items) LOOP
    INSERT INTO public.combo_items (combo_id, product_id, variant_id, quantity, sort_order)
    VALUES (
      v_id,
      (v_item ->> 'product_id')::uuid,
      NULLIF(v_item ->> 'variant_id', '')::uuid,
      (v_item ->> 'quantity')::integer,
      v_index
    );
    v_index := v_index + 1;
  END LOOP;

  RETURN v_id;
END;
$$;

REVOKE ALL ON FUNCTION public.admin_create_combo(text, text, text, jsonb) FROM public, anon;
GRANT EXECUTE ON FUNCTION public.admin_create_combo(text, text, text, jsonb) TO authenticated;

-- ------------------------------------------------------------------- D
-- One combo by its code: name, note, picture and lines. Null when the
-- code is unknown or the combo was deleted. Prices and stock are NOT
-- here: the customer page reads today's from the shop, like every page.
CREATE OR REPLACE FUNCTION public.get_combo(p_code text)
RETURNS jsonb
LANGUAGE sql
STABLE
SECURITY DEFINER
SET search_path = public
AS $$
  SELECT jsonb_build_object(
    'code', c.code,
    'name', c.name,
    'note', c.note,
    'preview_url', c.preview_url,
    'items', coalesce((
      SELECT jsonb_agg(
        jsonb_build_object('product_id', i.product_id, 'variant_id', i.variant_id, 'quantity', i.quantity)
        ORDER BY i.sort_order
      )
      FROM public.combo_items i
      WHERE i.combo_id = c.id
    ), '[]'::jsonb)
  )
  FROM public.combos c
  WHERE p_code ~ '^[a-z2-9]{8}$' AND c.code = p_code;
$$;

REVOKE ALL ON FUNCTION public.get_combo(text) FROM public;
GRANT EXECUTE ON FUNCTION public.get_combo(text) TO anon, authenticated;

COMMIT;
-------------------------------- copy to here ----------------------------------

To check it worked, run:
  select to_regclass('public.combos') as combos, to_regclass('public.combo_items') as items;
Both should show a name (not null).
